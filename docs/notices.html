This page identifies the third-party components carried by the current Windows packaging input and links to their licenses and source references. It does not change those licenses or provide legal advice.

FFmpeg Windows runtime

The public Windows release workflow pins ffmpeg.exe identified by its version banner as 8.1.2-full_build-www.gyan.dev and verifies the publisher-provided SHA-256 before packaging. It is Gyan's static full build and reports GPL-enabled configuration.

  • Gyan FFmpeg build information and license status
  • Upstream FFmpeg n8.1.2 source tag
  • GNU GPL v3.0 license text
  • FFmpeg licensing information

The full build contains FFmpeg and additional third-party libraries. Its exact composition, notices, and source obligations depend on the particular Gyan build distributed; it is not covered by ScriptSurgeon's MIT license.

Local speech model

The current package input uses Systran/faster-whisper-base, a CTranslate2 conversion of openai/whisper-base. The model card lists its license as MIT.

  • Model card, files, and conversion details
  • MIT license text
  • faster-whisper project license

The model and its tooling remain subject to their own terms and notices.

FFmpeg macOS runtime

The macOS release workflow compiles the native ffmpeg executable from the signed FFmpeg 9.0.1 source archive. It verifies the upstream signature before compiling a static, architecture-matched runtime with GPL and version3 code disabled.

  • FFmpeg release signing key
  • FFmpeg licensing and legal information
  • ScriptSurgeon macOS FFmpeg build configuration

This is a separate runtime from the Windows Gyan full build. The release log records its exact configuration and source verification. The macOS package also includes PyAV through faster-whisper; its wheel carries separate media-library components, including MP3 and GPL-bearing components. Keep the applicable upstream notices and source/build references with each redistributed asset.

Release distribution

Release maintainers should keep the notice, applicable upstream notices, and exact source/build references aligned with the components in each published asset. A different FFmpeg binary or model needs an updated notice. See the repository's third-party notices for the release-facing source record.
